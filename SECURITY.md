# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

We take the security of `crm-ticket-system` seriously. If you discover a security vulnerability, please do NOT create a public issue.

Instead, please send an email to **iletisim@egeleon.com** with:
- A description of the vulnerability.
- Steps or a proof-of-concept to reproduce the issue.
- Potential impact and affected components.

We will acknowledge your report within 48 hours and provide regular updates on the resolution.
